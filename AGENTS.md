# Project Rules & Workflow Instructions

## 1. Implementation Plan Requirement
- **Plan First**: Before writing or modifying any code in this repository, always prepare a detailed implementation plan in markdown format (`.md` file / artifact).
- **Approval Gate**: Always ask the user for confirmation to proceed before executing any code changes.
- **Strict Adherence**: Do not make code edits until the user has explicitly reviewed and approved the implementation plan.
